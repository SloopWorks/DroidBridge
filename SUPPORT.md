# DroidBridge beta support

Report ordinary bugs in [GitHub Issues](https://github.com/SloopWorks/DroidBridge/issues).
Include your Mac model, macOS version, Android model/version, DroidBridge version
and build number, connection type, steps to reproduce and expected/actual result.
State whether the native or scrcpy backend was selected. Review and redact any
logs before attaching them. Never include a pairing QR/link or signing credential.

The packaged beta targets Apple Silicon Macs running macOS 26 or later and
Android 13 or later with debugging authorized. Physical Pixel verification is
still pending; emulator results do not establish physical-device compatibility.
See [KNOWN_ISSUES.md](KNOWN_ISSUES.md) and [COMPATIBILITY.md](COMPATIBILITY.md).

Use the official versioned release assets for manual updates. Quit DroidBridge
and its generated wrappers before replacing the application. Follow the update
and uninstall instructions in [BUILD.md](BUILD.md). The current release does not
provide automatic updates or a paid license purchase flow.

For a suspected vulnerability, follow [SECURITY.md](SECURITY.md).
